# Filings

One folder per client. Drop the JSON files exported by the e-filing utility in.

    filings/ACME-PVT-LTD/AY2021-22/ITR6_2021-22.json
    filings/ACME-PVT-LTD/AY2021-22/3CA-3CD_2021-22.json
    filings/SHAH-TRADERS/anything.json

File names do not matter and neither do the year subfolders: whether a file is
a return or an audit report, which form it is, and which assessment year it
belongs to are all read out of the contents. Group by year if it helps you find
things; the analysis works either way.

Missing years are fine — reporting what is absent is half the point.
